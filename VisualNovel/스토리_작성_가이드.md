# 스토리 작성 가이드

스토리는 **메모장으로 쓰는 .txt 파일**입니다. 코드는 몰라도 됩니다.

- 스토리 파일 위치: `Assets/Resources/Story/`
- 새 게임은 `start.txt`부터 시작합니다. (씬의 `VN` 오브젝트 → `Start Script`에서 변경 가능)
- 파일은 **UTF-8**로 저장하세요. (메모장/VS Code의 기본값)
- 다 쓰고 나면 Unity 상단 메뉴 **VN → 스토리 파일 검사**를 눌러 보세요. 오타, 없는 라벨, 빠진 이미지를 찾아 줍니다.

---

## 1. 대사와 나레이션

```
유나: 안녕! 오늘 날씨 좋다.          ← 이름: 대사
유나(웃음): 같이 갈래?               ← 이름(표정): 대사  → 대사와 함께 표정이 바뀜
봄바람이 분다.                      ← 그냥 쓰면 나레이션 (이름 없음)
> 시각은 3:00. 종이 울렸다.          ← > 로 시작하면 무조건 나레이션
```

- 한 줄 = 한 번 클릭.
- 줄 안에서 줄바꿈을 하려면 `\n`을 쓰세요. 예: `유나: 그게…\n아니야!`
- 이름에는 **띄어쓰기가 없어야** 이름으로 인식합니다. (`???: 누구야?`는 가능)
- 나레이션 앞부분에 `단어:`가 있으면 대사로 잘못 인식될 수 있어요. 그럴 땐 앞에 `>`를 붙이세요.
- `{변수이름}`은 변수 값으로 바뀝니다. 예: `현재 호감도: {유나호감도}`
- `//`로 시작하는 줄은 주석입니다. (게임에 표시되지 않음)

## 2. 명령어 (`@`로 시작)

| 명령어 | 설명 | 예시 |
|---|---|---|
| `@bg 이름 [초]` | 배경 변경 (페이드 시간, 기본 0.5초) | `@bg 교실 1` |
| `@bg none` | 배경 지우기 (검은 화면) | |
| `@show 캐릭터 [표정] [위치]` | 캐릭터 등장 / 표정·위치 변경 | `@show 유나 웃음 left` |
| `@hide 캐릭터` | 캐릭터 퇴장 | `@hide 유나` |
| `@hide all` | 모든 캐릭터 퇴장 | |
| `@cg 이름 [초]` | 전체 화면 CG 표시 | `@cg 유나_고백 1` |
| `@cg off [초]` | CG 닫기 | |
| `@bgm 이름` | 배경음 재생 (반복) | `@bgm 메인테마` |
| `@bgm off [초]` | 배경음 정지 (페이드 아웃) | `@bgm off 2` |
| `@se 이름` | 효과음 1회 재생 | `@se 문소리` |
| `@wait 초` | 잠깐 멈춤 | `@wait 1.5` |
| `@color 이름 #색상` | 이름표 글자 색 | `@color 유나 #FF8FB1` |
| `@set 변수 = 값` | 변수 설정 (`+=`, `-=` 가능) | `@set 유나호감도 += 10` |
| `@if 조건 -> 이동할곳` | 조건이 맞으면 이동 | `@if 유나호감도 >= 30 -> 굿엔딩` |
| `@jump 이동할곳` | 이동 | `@jump 방과후` |
| `@end` | 게임 종료 → 타이틀로 | |

**위치**: `left`, `center`, `right` (또는 `왼쪽`, `가운데`, `오른쪽`) 또는 `0`~`1` 사이 숫자 (`0.35` 등)
- 위치를 생략하면 새 캐릭터는 가운데, 이미 나와 있는 캐릭터는 그 자리 그대로입니다.
- 표정을 생략하면 `기본` 표정입니다.

**조건 비교**: `>=`, `<=`, `>`, `<`, `==`, `!=`
- 변수는 숫자만 가능하고, 처음 값은 0입니다.

## 3. 라벨과 이동

```
# 라벨이름                ← # 으로 시작하면 라벨 (이동 목적지)

@jump 방과후               ← 같은 파일의 "# 방과후"로 이동
@jump chapter2            ← chapter2.txt 처음으로 이동
@jump ending:유나_엔딩      ← ending.txt 의 "# 유나_엔딩"으로 이동
```

라벨은 그냥 표시일 뿐이에요. 위에서부터 읽다가 라벨을 만나면 그냥 지나갑니다.
그래서 루트가 끝나면 꼭 `@jump`로 다른 곳으로 보내 주세요.

## 4. 선택지

```
@choice
- 유나와 점심을 먹는다 -> 유나_루트
- 서연과 도서관에 간다 -> 서연_루트
- 그냥 혼자 있는다                   ← -> 가 없으면 다음 줄로 그대로 진행
```

- `@choice` 바로 아래에 `-`로 시작하는 줄을 적으면 됩니다.
- 게임 중에는 클릭하거나 숫자키 1~9로 고를 수 있어요.

## 5. 이미지와 사운드 넣는 법

파일을 아래 폴더에 넣으면 됩니다. **파일 이름(확장자 제외)**이 스토리에서 쓰는 이름입니다.

| 종류 | 폴더 | 파일 이름 규칙 | 권장 크기 |
|---|---|---|---|
| 배경 | `Assets/Resources/Backgrounds/` | `교실.png` → `@bg 교실` | 1920×1080 |
| 캐릭터 | `Assets/Resources/Characters/` | `유나_웃음.png` → `@show 유나 웃음` | 세로로 긴 투명 PNG (예: 800×1400) |
| CG | `Assets/Resources/CG/` | `유나_고백.png` → `@cg 유나_고백` | 1920×1080 |
| 배경음 | `Assets/Resources/Audio/BGM/` | `메인테마.ogg` → `@bgm 메인테마` | ogg / mp3 / wav |
| 효과음 | `Assets/Resources/Audio/SE/` | `문소리.wav` → `@se 문소리` | ogg / mp3 / wav |
| 타이틀 배경 | `Assets/Resources/Backgrounds/` | `타이틀.png` | 1920×1080 |

- 지금 들어 있는 그림은 **전부 임시 이미지**입니다. 같은 이름으로 덮어쓰면 그대로 바뀝니다.
- 캐릭터 표정 이미지는 `이름_표정.png` 형식입니다. 표정이 하나뿐이라면 `이름.png`만 있어도 됩니다.
- 위 폴더에 넣은 이미지는 자동으로 Sprite로 설정됩니다.
- 캐릭터는 화면 아래쪽에 붙어서 높이 1000px로 표시됩니다. (`Canvas/Stage` → `Character Height`에서 조절)

## 6. 바꾸고 싶은 것들

| 바꾸고 싶은 것 | 위치 |
|---|---|
| 게임 제목 / 부제 / 타이틀 배경 | `Canvas/TitleMenu` 오브젝트의 Inspector |
| 시작 파일 / 테스트용 시작 라벨 / 타이틀 BGM | `VN` 오브젝트의 Inspector |
| 한글 폰트 | `VN` 오브젝트 → `Custom Font`에 .ttf/.otf 넣기 (비워두면 맑은 고딕) |
| UI 색, 위치, 크기 | 씬의 `Canvas` 아래 오브젝트를 직접 수정 |
| UI를 처음 상태로 되돌리기 | 메뉴 **VN → 메인 씬 다시 생성** (직접 수정한 내용은 사라짐) |

**테스트 팁**: 긴 스토리를 처음부터 다시 보기 귀찮으면 `VN` 오브젝트 → `Start Label`에 라벨 이름을 적으세요. 새 게임을 누르면 거기서부터 시작합니다. (배포 전에는 비워 두세요!)

## 7. 게임 조작

| 조작 | 기능 |
|---|---|
| 클릭 / Space / Enter | 다음 대사 (글자가 나오는 중이면 한 번에 표시) |
| Ctrl 누르고 있기 | 빨리 넘기기 |
| 마우스 오른쪽 / H | 대사창 숨기기 |
| 마우스 휠 위로 | 대사 로그 |
| Esc | 열린 메뉴 닫기 |
| 1~9 | 선택지 고르기 |

## 8. 주의사항

- 세이브는 "몇 번째 줄인지"를 기억합니다. 게임을 배포한 뒤 스토리 파일 중간에 줄을 추가하거나 지우면 예전 세이브 위치가 어긋날 수 있어요.
- 세이브 파일 위치는 메뉴 **VN → 세이브 폴더 열기**에서 볼 수 있어요.
