//    엔딩 기준 (숫자만 바꾸면 돼요)
//      넷 다 55 이상        → 하렘엔딩
//      1등이 80 이상        → 그 친구 엔딩 (동점이면 승현 → 서연 → 기주 → 수민 순)
//      그 외                → 솔로엔딩
//    @ending 이름 → 갤러리 '엔딩' 목록에 해금 / @cg 이름 → 갤러리 'CG' 목록에 해금
// ==========================================================

@bg 옥상 1
@bgm 메인테마
> [작성] 축제가 끝난 옥상. 편지에 적힌 대로 넷이 전부 와 있다
@show 승현 기본
@show 서연 기본
@show 기주 기본
@show 수민 기본
승현: [작성] 이제 골라 줘
> [작성] 승주 속마음


// ───────── 판정 (1등 찾기) ─────────
@if 승현호감도 < 55 -> 1등찾기
@if 서연호감도 < 55 -> 1등찾기
@if 기주호감도 < 55 -> 1등찾기
@if 수민호감도 < 55 -> 1등찾기
@jump 하렘엔딩

# 1등찾기
@set 최고점 = 승현호감도
@set 1등 = 1
@if 서연호감도 > 최고점 -> 서연이1등
# 기주비교
@if 기주호감도 > 최고점 -> 기주가1등
# 수민비교
@if 수민호감도 > 최고점 -> 수민이1등
@jump 결과

# 서연이1등
@set 최고점 = 서연호감도
@set 1등 = 2
@jump 기주비교

# 기주가1등
@set 최고점 = 기주호감도
@set 1등 = 3
@jump 수민비교

# 수민이1등
@set 최고점 = 수민호감도
@set 1등 = 4
@jump 결과

# 결과
@if 최고점 < 80 -> 솔로엔딩
@if 1등 == 1 -> 승현엔딩
@if 1등 == 2 -> 서연엔딩
@if 1등 == 3 -> 기주엔딩
@jump 수민엔딩
